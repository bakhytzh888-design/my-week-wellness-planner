# Моя неделя

Небольшое статическое веб-приложение для недельного планирования: работа, спорт, семья, питание и привычки.

## Запуск на компьютере

Откройте файл `index.html` двойным щелчком в любом современном браузере. Подключение к интернету не требуется.

## Возможности

- Расписание недели с категориями событий;
- Тренажёрный зал, йога, бассейн и танцы;
- Семья, встречи и ежедневное чтение перед сном;
- Меню на неделю с ранним лёгким ужином и белковыми блюдами;
- Отметки привычек, индикатор выполнения и добавление собственных привычек;
- Сохранение отметок только в браузере пользователя (`localStorage`).

## Технологии

Обычные HTML, CSS и JavaScript в одном файле. Нет сервера, базы данных, API-ключей, внешних библиотек, подписок или платных сервисов.

## Публикация на GitHub Pages

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в корень репозитория файл `index.html` из этой папки.
3. В настройках репозитория откройте **Pages**.
4. Выберите публикацию из ветки `main`, папка `/ (root)`, и сохраните настройки.

После этого GitHub покажет адрес опубликованной страницы. Для работы локально публикация не нужна.
